# نقشه راه غیرخطی

شماره EXP/PR برای شناسایی است و ترتیب زمانی اجباری ایجاد نمی‌کند.

## مسیرهای کاری موازی
- مسیر شناخت و شواهد: EXP-01,03,04,05,06,07,10
- مسیر دوام و عملیات: EXP-02,16,17,18
- مسیر کسب‌وکار: EXP-08,09
- مسیر سازمان و امنیت: EXP-11,12,13,14,19
- مسیر راهکار و تحویل: EXP-15,20,21,22,23,24,25,26,27

## وابستگی‌های سخت
- تغییر مخرب داده ← خط مبنا و بکاپ/restore معتبر (EXP-01/02/17).
- طراحی migration ← شناخت مدل داده و سازگاری (EXP-11).
- تغییر مجوز ← مدل نقش/مجوز و تست deny-by-default (EXP-12/13).
- تغییر پرداخت ← شناخت جریان موجود و قرارداد gateway (EXP-08/10).
- انتشار ← تست‌های لازم، rollback و تأیید انسانی (EXP-18/23/24/26).
- تصمیم حقوقی ← متخصص حقوقی؛ عامل فقط تحقیق و آماده‌سازی می‌کند.

## استقلال
تحلیل امنیتی، کاتالوگ قابلیت، بررسی سرویس هوشمند و سناریوهای محصول می‌توانند هم‌زمان پیش روند اگر منابع نوشتنی مشترک نداشته باشند. وابستگی اطلاعاتی با وابستگی اجرایی یکسان نیست؛ خروجی موقت با برچسب provisional قابل استفاده است.

## دروازه‌ها
GATE-01 baseline; GATE-02 backup; GATE-03 evidence; GATE-04 authorization; GATE-05 host feasibility; GATE-06 regression; GATE-07 restore; GATE-08 human acceptance; GATE-09 release approval.
