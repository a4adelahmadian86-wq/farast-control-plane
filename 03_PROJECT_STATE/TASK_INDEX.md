# فهرست وظایف

GitHub Issues منبع اصلی وضعیت وظایف است. این فایل فقط فهرست تجمیعی و پیوندی است؛ با Issueها تناقض نداشته باشد.

## شناسه‌گذاری
- TASK ID = شناسه پایدار مثل `FCP-EXP03-001`؛ Issue number مرجع GitHub است.
- یک وظیفه برای یک خروجی/معیار پذیرش مشخص.
- وظایف مشابه قبل از ایجاد جدید جست‌وجو شوند.
- وظیفه ادامه‌دار همان TASK ID را نگه می‌دارد.

## وضعیت‌های مجاز
BACKLOG, READY, CLAIMED, IN_PROGRESS, BLOCKED, REVIEW, DONE_UNVERIFIED, DONE_VERIFIED, CANCELLED, SUPERSEDED.

## ثبت
هنوز Issue اجرایی ایجاد نشده است. وظایف با اجرای پرامپت‌ها و پس از بررسی تکراری نبودن ایجاد می‌شوند.
