# فهرست کتابخانه پرامپت‌های اجرایی FARAST

## نسخه یکپارچه

برای کپی یکجای همه پرامپت‌ها: [FARAST_EXECUTABLE_PROMPTS_COMPLETE.md](FARAST_EXECUTABLE_PROMPTS_COMPLETE.md) (نسخه 1.7.0؛ بازتولیدشده از ۱۷ پرامپت مستقل و MASTER-00). نسخه‌های مستقل و قابل به‌روزرسانی در همین پوشه مرجع‌اند.

## زمینه پروژه
نیازمندی‌های اجرای چندچتی در [CONTROL_PLANE_REQUIREMENTS.md](../00_PROJECT_FOUNDATION/CONTROL_PLANE_REQUIREMENTS.md) و بازخورد مالک در دفتر مرکزی ثبت شده‌اند.

## راهنمای مبتدی

راهنمای گام‌به‌گام: [USAGE_GUIDE_FA.md](../USAGE_GUIDE_FA.md). پرامپت‌ها مستقل‌اند و متن مشترک لازم را درون خود دارند؛ کاربر لازم نیست MASTER-00 را دستی به هرکدام بچسباند.

## اجرای یک متن واحد در چند چت
برای اجرای موازی، MASTER-00 را بدون تغییر در تمام چت‌ها بفرستید و پروتکل [پخش یک پرامپت واحد](../04_COORDINATION/SINGLE_PROMPT_MULTI_CHAT_DISPATCH.md) را رعایت کنید. هر چت از GitHub یک leaf Work Item آزاد را claim می‌کند؛ در رقابت، بازنده پس از read-back برگ بعدی را می‌گیرد. تا E2E دو حساب مستقل، این قابلیت تأییدشده نیست.

## قانون استفاده
1. برای مأموریت عمومی/هماهنگی که پرامپت تخصصی مشخصی ندارد، `MASTER-00.md` را کپی و اجرا کن.
2. برای مأموریت تخصصی، فقط همان پرامپت PR-01 تا PR-17 را کپی کن؛ متن هر پرامپت دروازه اجباری را در خود دارد و عامل باید `START_HERE.md`، `INTERRUPTION_RECOVERY_PROTOCOL.md` و `MASTER-00.md` را مستقیماً از GitHub بخواند. لازم نیست MASTER-00 را جداگانه به متن پرامپت تخصصی بچسبانی.
3. PRها ترتیب زمانی ندارند؛ وابستگی واقعی و قفل منابع تعیین‌کننده است.
4. برای ادامه کار، همان پرامپت را دوباره بده یا بگو «ادامه بده»؛ TASK_ID و checkpoint مانع شروع مجدد می‌شوند.
5. خروجی نهایی و گزارش‌ها در GitHub ثبت می‌شوند؛ چت فقط خلاصه و لینک می‌دهد.

## نقش‌ها
- AI: تحلیل، استخراج، نقشه‌برداری، تهیه پیشنهاد، تولید تست و اجرای مجاز.
- AI + Human: اجرای واقعی، تأیید رفتار، پذیرش خروجی و تصمیم‌های محصول.
- متخصص انسانی: حقوق، تست نفوذ رسمی، تصمیم معماری پرریسک، restore/production و review مستقل.
- مالک محصول: تأیید دامنه، هزینه، ریسک، تغییرات حساس و انتشار.

## محدودیت
این کتابخانه ابزار اجرا را تعریف می‌کند، اما وجود دسترسی GitHub، Work، shell، مرورگر، runtime یا حساب‌های بیرونی را تضمین نمی‌کند. هر اجرا باید قابلیت واقعی ابزارها را بررسی کند.
