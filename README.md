# FARAST Control Plane

مرکز کنترل مستقل پروژه FARAST؛ منبع حقیقت مشترک برای چت‌ها، حساب‌ها و همکاران انسانی.

> این مخزن از مخزن محصول `a4adelahmadian86-wq/non` مستقل است. این مخزن کد اجرایی سایت را نگهداری نمی‌کند و هیچ تغییر محصولی را بدون مجوز صریح و گردش‌کار Pull Request مجاز نمی‌داند.

## شروع سریع
1. `START_HERE.md` را بخوانید.
2. `00_PROJECT_FOUNDATION/APPROVED_REQUIREMENTS.md` و `SPECIALIST_WORKFLOW.md` را مطالعه کنید.
3. پیش از اجرای هر وظیفه، `04_COORDINATION/WORKER_PROTOCOL.md`، `LOCK_PROTOCOL.md` و `TASK_SCHEMA.md` را اجرا کنید.
4. فقط وظیفه دارای شناسه یکتا و مالکیت معتبر را ادامه دهید.
5. شواهد، checkpoint، بازخورد و نتیجه را در همین مخزن ثبت کنید.

## اصل منبع حقیقت
- وضعیت جاری: `03_PROJECT_STATE/MASTER_STATUS.md`
- درخت اهداف و نقشه راه: `01_STRATEGY/`
- نیازمندی‌ها و تصمیم‌های مصوب: `00_PROJECT_FOUNDATION/` و `02_GOVERNANCE/`
- وظایف: GitHub Issues با قالب استاندارد
- پرامپت‌ها: `05_PROMPT_LIBRARY/`
- گزارش‌ها و checkpointها: `07_CHECKPOINTS/` و `08_REPORTS/`

## وضعیت اولیه
مخزن تازه ایجاد شده است. فایل‌های این commit، خط مبنای اولیه کنترل‌پلین هستند؛ هیچ‌یک به معنای اجرای ممیزی یا تأیید عملیاتی سایت نیستند. داده‌های نامعلوم صریحاً در `00_PROJECT_FOUNDATION/KNOWN_UNKNOWN.md` نگهداری می‌شوند.
