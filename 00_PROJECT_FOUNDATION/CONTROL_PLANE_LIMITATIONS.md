# محدودیت‌های عملیاتی Control Plane نسخه 1

1. مخزن هنگام راه‌اندازی با visibility برابر PUBLIC مشاهده شد. محتوای پروژه و نیازمندی‌ها حساس است؛ مالک باید فوراً از Settings → General → Danger Zone → Change repository visibility آن را به PRIVATE تغییر دهد. تا آن زمان هیچ داده محرمانه، کلید، PII، dump یا اطلاعات مشتری وارد نشود.
2. قفل منابع در نسخه فعلی تعاونی است؛ سرویس lock اتمیک وجود ندارد. این محدودیت در LOCK_PROTOCOL و تمام پرامپت‌ها اعلام شده است.
3. GitHub Actions validation فقط وجود فایل‌های لازم و تعداد پرامپت‌ها را بررسی می‌کند؛ کیفیت معنایی، هماهنگی بین عامل‌ها یا رفتار runtime را اثبات نمی‌کند.
4. چت‌های مختلف از طریق این repo context مشترک دارند، اما GitHub به‌تنهایی نمی‌تواند هویت واقعی مکالمه ChatGPT را اثبات کند.
5. کنترل‌پلین مخزن کد سایت نیست و نباید secrets یا داده عملیاتی مشتری در آن نگهداری شود.
6. تا زمان فعال‌شدن branch protection، PR review و قواعد required checks در تنظیمات GitHub، الزام‌های review در سطح پروتکل/همکاری هستند، نه enforcement فنی قطعی.
