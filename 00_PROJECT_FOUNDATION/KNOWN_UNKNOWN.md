# مجهولات و موارد نیازمند اثبات

این فهرست عمداً مانع حدس‌زدن است. هر عامل باید پیش از تصمیم وابسته، وضعیت را با شواهد به‌روز کند.

| موضوع | وضعیت فعلی | روش اثبات/اقدام |
|---|---|---|
| هاست نهایی سایت | نامشخص؛ سایت فعلاً محلی گزارش شده | دسترسی مالک و پنل هاست، بررسی قرارداد و runtime |
| دامنه/محیط تولید | تأیید نشده | بررسی DNS و تنظیمات از منبع مجاز |
| Voice-typing روی Render | manifest قبلی پلن پولی نشان می‌داد؛ billing واقعی نامعلوم | بررسی داشبورد/صورتحساب با مجوز مالک |
| سرویس‌های خارجی رایگان | نامشخص | ارزیابی terms، quota، privacy و هزینه واقعی |
| بکاپ خارجی فعال | اثبات نشده | بررسی مقصد، آخرین artifact، checksum و restore |
| تست restore تولید | اثبات نشده | restore در محیط ایزوله با مجوز |
| آستانه ظرفیت و performance | عدد مصوب ندارد | نیازسنجی و load test در محیط مجاز |
| تعداد کاربران/سال | نامعلوم | برآورد مالک محصول |
| فرایند نهایی احراز هویت | تصمیم حقوقی نهایی ندارد | مشاوره حقوقی و بررسی قوانین روز |
| دوره‌های نگهداری داده | نیازمند تطبیق حقوقی | نظر وکیل و جدول نگهداری |
| دسترسی چت‌ها به ابزارها | در هر حساب متفاوت | آزمون واقعی قابلیت و مجوز در هر اجرا |
| قفل اتمیک بین عامل‌ها | این مخزن فعلاً فاقد سرویس قفل مستقل است | پروتکل تعاونی + PR و محافظت شاخه؛ عدم ادعای قفل سخت |
| سطح دسترسی repo | در لحظه ایجاد public مشاهده شد | مالک باید visibility را private کند |
| branch protection | هنوز پیکربندی نشده | تنظیم در GitHub UI/API و راستی‌آزمایی |

هر مورد پس از اثبات باید همراه با منبع، زمان، روش و مسئول به‌روزرسانی شود. داده حساس یا راز را وارد مخزن نکنید.
